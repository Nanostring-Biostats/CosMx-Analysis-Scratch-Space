InSituTree hierarchical cell typing

Claire Williams

2024-11-26

Overview

The InSituTree package is a small package that builds on InSituType and provides a specialized application for its use. With this approach, you can perform supervised cell typing in a hierarchical manner – first making broad cell type assignments and then making progressively finer classifications.

Installation

# Download the package and install from file
devtools::install("/path/to/package/InSituTree.zip")

Optional inputs

The remaining inputs to InSituTree are optional, with some having default values.

  1. A vector of cohorts provides a grouping of cells based on alternative data types, such as immunofluorescent staining, cell shape metrics, tissue structures, etc. In this small example we will not use cohorts, but it is generally recommended. The random vector below is provided to give an example of the expected structure. See the InSituType package for more information about how to generate cohorts.
# These will not be used in this vignette and should not be random. This is an example to show the structure.
set.seed(2024)
example_cohorts <- sample(1:30, size = ncol(counts), replace = TRUE)
  1. A character vector of genes to exclude from the cell typing. Often these will be highly and broadly expressed genes in the CosMx dataset that we don’t want to influence the cell typing. Defaults to NULL.
genes_to_exclude <- c("MALAT1")
  1. A numeric value between 0 and 1 that indicates the quantile of absolute difference for a given gene between the cell type with the highest expression and that with the lowest expression for a gene to be included in cell typing. Only genes in the quantile above this level and above the next quantile level will be considered. Defaults to 0.5.
quantile_abs_difference <- 0.5

# For reference, the absolute differences in expression for a set of five genes across the whole ioprofile are:
diffs <- sapply(c("CD3D", "CD3E", "JCHAIN", "KRT18", "VIM", "MALAT1"), function(gene){
    diff(range(ioprofiles[gene, ]))
  } )
diffs
#>        CD3D        CD3E      JCHAIN       KRT18         VIM      MALAT1 
#>   1243.0416   2353.2094 301705.8527    108.1911  18024.1937  59850.4078

# The 50% quantile is:
quantile(diffs, 0.5)
#>     50% 
#> 10188.7

# Genes from the first five passing this filter if only five were considered:
names(diffs)[diffs > quantile(diffs, quantile_abs_difference, na.rm = T)]
#> [1] "JCHAIN" "VIM"    "MALAT1"
  1. A numeric value between 0 and 1 that indicates the quantile of percentage difference for a given gene between the cell type with the highest expression and that with the lowest expression for a gene to be included in cell typing. Only genes in the quantile above this level and above the previous quantile level will be considered. Defaults to 0.5.
quantile_perc_difference <- 0.5

# For reference, the percent differences in expression for a set of five genes across the whole ioprofile are:
percs <- sapply(c("CD3E", "JCHAIN", "KRT18", "VIM", "MALAT1"), function(gene){
    diff(range(ioprofiles[gene, ])) / max(ioprofiles[gene,])
  } )
percs
#>      CD3E    JCHAIN     KRT18       VIM    MALAT1 
#> 0.9998957 0.9999837 0.9924013 0.9540667 0.8778193

# The 50% quantile is:
quantile(percs, 0.5)
#>       50% 
#> 0.9924013

# Genes from the first five passing this filter if only five were considered:
names(percs)[percs > quantile(percs, quantile_perc_difference, na.rm = T)]
#> [1] "CD3E"   "JCHAIN"

The only gene passing both of the above filters is JCHAIN, and so in this small example where we’re considering all cell types together and only five genes, only this gene would be considered as having high differentiating power. Note that when fewer cell types are considered after merging subtypes we expect to see more variability in the diffs and percs.

  1. A logical value indicating whether to return the final summary annotation. This data frame shows the annotation that has been made for each cell at each level of the annotation tree. Recommendation is to keep this at its default value of TRUE.
return_summary_df <- TRUE

Once we’ve verified that this tree shows the hierarchy and cell type relationships that we’d expect, we can run supervised nested cell typing.

res <- runInSituTree(x = counts,
                          neg = negmean,
                          full_profiles = ioprofiles,
                          cth = celltype_hierarchy_list,
                          name_for_new_annotation = annotation_names,
                          cohort = NULL,
                          excluded_genes = genes_to_exclude,
                          quantile_absolute_expression_difference_param = quantile_abs_difference,
                          quantile_percent_expression_difference_param = quantile_perc_difference,
                          return_summary_annotation = return_summary_df)

Review results

The results from running InSituTree contain two main components:

  1. Nested list of results from each run of InSituTypeML

  2. Summary of annotations at each level of the tree

The nested results list contains the typical outputs of InSituType for each round of cell typing, as well as one additional metric: the counts per cell for each cell for the given round of subclustering. We include counts per cell among the genes considered for each subclustering as an additional metric since cell assignments for low-count cells are likely to be less confident. As an example, we look at the first major cell types assignment and use the flightpath tool from InSituType to visualize how well cells were assigned to these major types.
