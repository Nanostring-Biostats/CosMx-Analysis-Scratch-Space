# HieraType
An R Package for Hierarchical Cell Typing using Smoothed Metagene Scores

### Installation
```
remotes::install_github("Nanostring-Biostats/CosMx-Analysis-Scratch-Space", 
                        subdir = "_code/HieraType", ref = "Main")

```
#### Examples and vignettes

Please see this [post](https://nanostring-biostats.github.io/CosMx-Analysis-Scratch-Space/posts/immune-cell-typing-smooth/) for code examples and detailed methods descriptions.

For a demonstration of how to use HieraType with multiomic data, please see this [post](https://nanostring-biostats.github.io/CosMx-Analysis-Scratch-Space/posts/multiomics-hieratype/), where we also discuss performance benefits we've found from using both RNA and protein for cell typing.
