# HieraType
An R Package for Hierarchical Cell Typing using Smoothed Metagene Scores

### Installation
```
remotes::install_github("Nanostring-Biostats/CosMx-Analysis-Scratch-Space", 
                        subdir = "_code/HieraType", ref = "Main")

```
#### Examples and vignette

Please see this [post](https://nanostring-biostats.github.io/CosMx-Analysis-Scratch-Space/posts/immune-cell-typing-smooth/) for code examples and demonstration.
